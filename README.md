# Map demos by Bogdan Shutov

Live site: https://spiller250.github.io/home-builder-demos/

Interactive map demos built with plain JavaScript and [Leaflet](https://leafletjs.com/). No build step and no framework.

| Demo | File | What it shows |
|---|---|---|
| Homesite map for home builders | `lots.html` | Click a lot to see status, size, price and fitting house plans. Filter by status, phase, price and size. Link to one lot with `#lot-12`. |
| Route map for tour operators | `tour.html` | Day tabs, a timetable of stops, distance and walking time, step-through navigation. |
| Installer finder for brands | `finder.html` | Search by town, service filters, marker clustering, nearest-first sorting with browser location, shareable search links like `#q=leeds&svc=bat`. |

The community, the installer brand and their data are invented. The Edinburgh itinerary is a sample. Map data © OpenStreetMap contributors.

Real project: [Temirtau GIS platform](https://github.com/Spiller250/temirtau-gis-platform), [live site](https://temirtauupcois.vercel.app/).

Libraries: Leaflet 1.9.4 (BSD-2-Clause) and Leaflet.markercluster 1.5.3 (MIT) from cdnjs. Fonts from Google Fonts (SIL Open Font License).
